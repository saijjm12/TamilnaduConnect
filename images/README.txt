Put your photos in this folder using these exact filenames so they connect automatically:

- Village_bg.png       -> Village Stories banner (homepage)
- tirunelveli.png       -> Tirunelveli story page photo
- kanyakumari.png       -> Kanyakumari story page photo
- dindigul.png          -> Dindigul story page photo
- coimbatore.png        -> Coimbatore story page photo

Filenames are case-sensitive. If a photo isn't added yet, that section just shows
a plain green color instead of a broken image icon.
